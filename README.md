# 起身 · Stand Reminder

一个给长期在电脑前学习、工作的人使用的桌面久坐提醒工具。当前版本是可运行的基础框架，默认专注 45 分钟、活动 5 分钟。

## 开始使用

需要 Node.js 22.12+（或 24 LTS）及 npm。在本目录运行：

```powershell
npm install
npm run dev
```

开发模式会打开 Electron 桌面窗口。首次安装需要下载 Electron，耗时取决于网络。仅在浏览器中打开页面无法使用桌面计时和全屏提醒。

```powershell
npm test          # 状态机与持久化测试
npm run build    # TypeScript 检查与生产构建
npm start        # 启动已构建的桌面应用
npm run test:desktop # 构建后运行真实 Electron 冒烟测试，会短暂显示全屏提醒
npm run test:desktop -- --dev # 同时验证开发服务和 React 页面加载
npm run dist     # 构建 Windows 便携 EXE，输出至 release/
```

打包命令会下载额外的构建工具；当前没有配置代码签名。macOS / Linux 尚未进行实际兼容验证。

## 已有功能

- 专注与活动倒计时、暂停/继续、重置、立即活动。
- 到期弹出置顶全屏提醒，默认覆盖所有显示器，可切换为只提醒主屏幕。
- 休息结束后由用户确认继续；休息中可以跳过，或按 Esc / 点击稍后提醒延后。
- 关闭主窗口后显示紧凑的透明置顶桌宠（约 156×190 像素），桌宠展示本轮已持续工作时间；通过桌宠可暂停、重置、隐藏或退出。
- “桌宠衣橱”可以预览和选择桌宠，选择结果保存在本机；当前内置“小芽同学”。
- 桌宠隐藏后继续在托盘运行；托盘菜单可以重新显示桌宠或打开主界面。
- 系统锁屏和睡眠时暂停，返回后继续剩余计时。
- 设置与当日完成活动数保存到本机；本地每日寄语。
- 中文界面，扩展空间展示后续功能规划。

统计只表示完整走完的活动倒计时，不检测身体动作。当前“专注”按应用运行时间计时，不检测键鼠活动；重启应用重新开始一轮，不恢复上次倒计时。修改时长在下一阶段生效，可点击重置立即开始新一轮。系统锁屏/睡眠之外的离开电脑不会自动暂停。

## 代码组织

```text
src/
  main/
    index.ts            Electron 生命周期、托盘、IPC、窗口和系统事件
    timer.ts            不依赖 Electron 的计时状态机
    store.ts            设置、每日统计、原子写入与损坏配置备份
    extensions/index.ts 内容提供器接口与本地每日寄语
  preload/index.ts      只暴露限定操作的桌面 API
  shared/types.ts       跨进程类型、默认值、输入验证
  renderer/src/
    App.tsx              首页、设置、扩展列表、全屏提醒
    Pet.tsx              桌宠窗口、工作时长与快捷操作
    PetPicker.tsx        桌宠选择与预览界面
    pets.ts              可替换桌宠形象目录
    extensions.ts        扩展展示目录
    styles.css           界面样式
tests/                   状态机与持久化测试
scripts/smoke.cjs         真实 Electron 冒烟测试
```

主进程拥有计时和数据；React 只负责展示和发送操作，不会因为主窗口关闭或渲染限速而停止计时。状态每 250ms 同步到窗口。使用单调时钟避免系统时间调整影响间隔，使用本地日期统计当天活动。

数据存放在 Electron 的 `app.getPath('userData')/settings.json`，Windows 开发环境通常为 `%APPDATA%/stand-reminder/settings.json`。不上传个人数据，不需要账号。无法写入磁盘时界面会显示错误；损坏文件读取时会尽量保留备份。

## 后续怎么扩展

详见 [扩展设计](docs/EXTENSIONS.md)。规划中的今日计划、动漫角色和 AI 文案目前仅提供入口与接口，没有伪装成已实现功能。

## 手动验收

1. 运行后暂停，确认计时不再变化；继续、重置均应正常。
2. 点击“现在就活动一下”，确认全屏提醒；Esc 后返回工作计时且为设定的延后时长。
3. 将专注与活动时长都设为 1 分钟，保存并重置。等待自然到期，活动计时完成后今日完成数增加 1；点击继续开始下一轮。
4. 关闭主窗口，确认右下角出现桌宠且工作时间继续增加；点击桌宠应重新打开主界面，托盘菜单也可重新显示桌宠。
5. 工作中锁屏 / 睡眠再返回，确认剩余时间保持；多显示器环境检查全屏覆盖、拔插显示器及只在主屏提醒。
6. 重启软件，确认设置和当天统计保留。Windows 独占全屏游戏、系统安全桌面可能遮挡普通置顶窗口，当前未做特殊处理。
